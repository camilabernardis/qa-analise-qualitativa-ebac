# QA – Análise Qualitativa (EBAC)

Exercício proposto no curso de Qualidade de Software (QA) da EBAC.

No primeiro exercício prático do curso, foi solicitado o desenvolvimento de um relatório de análise qualitativa sobre um produto ou serviço utilizado no dia a dia, com foco em avaliação de qualidade, usabilidade e experiência do usuário.

Para este exercício, foi analisado o teclado mecânico **Neologic Crystal Edge 65%**, adquirido em dezembro de 2025 e utilizado como teclado principal desde então.

**Exercício finalizado em:** 24/01/2026

## Conteúdo do repositório
- `Relatorio_Analise_Qualitativa_Neologic_Crystal_Edge_65.docx` — relatório final.
- `M2-modeloAnaliseQualidade.docx` — modelo fornecido pela EBAC.
- `M2-DIRETRIZ ABNT.docx` — diretrizes de formatação ABNT utilizadas.
